# TaskFlow Pro — Final College Submission

Features: JWT login/register, protected user-wise CRUD APIs, dashboard, My Tasks, Today, Upcoming, Overdue, Important, Calendar, Analytics, Notifications, Profile, Settings, responsive mobile/desktop UI, Socket.IO live refresh, SQLite database and PWA support.

Run:
1. pip install -r requirements.txt
2. python run.py
3. Open http://127.0.0.1:5000/
